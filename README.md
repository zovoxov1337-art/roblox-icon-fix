# 🛠️ Roblox Icon Fix

Серые заглушки вместо аватарок и обложек игр в Roblox? Эта утилита для Windows помогает восстановить загрузку изображений при проблемах с доступом к серверу картинок `tr.rbxcdn.com`.

## 🤙 Да, это лютый вайбкод

Проект собран с помощью ИИ, чтобы решить конкретную проблему: вернуть картинки в Roblox. На моём ПК помогло — выкладываю исходники и готовую программу, чтобы пригодилось другим.

Код открыт: можно изучать, дорабатывать и присылать исправления. Нашёл баг — заводи Issue, поправил — присылай Pull Request.

## ⚙️ Что умеет

- Получать адреса сервера изображений через Google и Cloudflare DNS-over-HTTPS.
- Проверять доступность найденных адресов.
- Исправлять запись `tr.rbxcdn.com` в файле `hosts`.
- Создавать резервную копию перед изменениями.
- Отменять внесённый фикс отдельной кнопкой.
- Показывать диагностику и сохранять журнал.

## 🚀 Как пользоваться

1. Скачай `RobloxIconFix.exe` из раздела **Releases**.
2. Полностью закрой Roblox.
3. Запусти утилиту и подтверди запрос прав администратора.
4. Нажми **«Исправить иконки»** и дождись результата.
5. Открой Roblox заново.

Для отмены изменений нажми **«Отменить фикс»**.

**Требования:** Windows 10 версии 1803+ или Windows 11, x64, встроенный `curl.exe`. Установка Python и .NET не требуется.

Фикс рассчитан на проблемы с конкретным сервером изображений. Работа во всех сетях и восстановление всех текстур внутри игр не гарантируются.
