# Участие в разработке

Для исправления ошибки приложи краткое описание причины и изменения поведения. Сохраняй ограничение: программа изменяет только записи `tr.rbxcdn.com` и не отключает TLS-проверки.

Перед pull request:

1. Запусти существующие тесты `tests/core_tests.cpp`.
2. Для изменений парсинга или отката hosts добавь тест, который воспроизводит конкретную ошибку.
3. Проверь Windows-сборку и укажи, что именно удалось проверить на реальной машине.
4. Сохраняй исходные права доступа к файлам, резервное копирование и отказ при конфликте сторонних изменений.

В репозиторий загружаются исходники. Готовые `.exe` и ZIP публикуются в Releases. Локальные журналы, резервные копии hosts, токены и персональные настройки в коммиты не включаются.
