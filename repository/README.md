# Roblox Icon Fix

**Серые прямоугольники вместо обложек игр?** Roblox Icon Fix помогает восстановить загрузку превью и аватарок, если причина связана с адресом сервера изображений `tr.rbxcdn.com`.

Windows 10 / 11 · x64 · Русский интерфейс · C++17 · MIT

[English](docs/README_EN.md) · [Подробная инструкция](README_RU.md) · [Что проверено](VALIDATION.md) · [История изменений](CHANGELOG.md)

## Скачать и запустить

В разделе **Releases** этого репозитория скачай **RobloxIconFix.exe** или архив **RobloxIconFix-v1.0.0-Windows-x64.zip**.

1. Полностью закрой Roblox.
2. Запусти `RobloxIconFix.exe` и подтверди запрос прав администратора.
3. Нажми **«Исправить иконки»** и дождись результата.
4. Открой Roblox заново. Утилиту можно закрыть.

Для запуска нужна Windows 10 версии 1803 или новее либо Windows 11, x64. Используется встроенный в Windows `curl.exe`; Python и .NET устанавливать не требуется.

## Возможности

| Действие | Что происходит |
| --- | --- |
| **Исправить иконки** | Получение адресов через DNS-over-HTTPS, проверка доступности и применение подходящего адреса |
| **Проверить** | Диагностика без изменения hosts |
| **Отменить фикс** | Удаление записей утилиты и восстановление прежних записей домена |
| **Открыть журнал** | Папка с результатами проверки и резервными копиями |

Перед применением проверяется HTTPS-соединение. Когда API Roblox доступен, программа также скачивает публичную тестовую картинку и проверяет её тип и сигнатуру. Если удалось проверить только HTTPS, интерфейс явно сообщает об этом.

Перед изменением создаётся резервная копия hosts. После применения выполняется повторная проверка через системное разрешение имени. При неудаче программа пытается вернуть предыдущие настройки; если файл успела изменить другая программа, она останавливается и сообщает о конфликте.

## Какие настройки меняются

Утилита изменяет записи **только для `tr.rbxcdn.com`** в файле:

```text
%SystemRoot%\System32\drivers\etc\hosts
```

Резервные копии и журналы находятся в соседней папке `RobloxIconFix-backups`. Прежние записи этого домена сохраняются для отката. Другие имена и строки hosts сохраняются.

Сетевые адаптеры, службы, драйверы и файлы клиента Roblox не изменяются. Пароль и cookie Roblox не нужны. Обращения выполняются к Google / Cloudflare DoH и публичным серверам Roblox. Проверка сертификатов HTTPS остаётся включённой.

## Когда может не помочь

Фикс рассчитан на проблемы DNS и доступности отдельных узлов CDN. Он не гарантирует результат при блокировке всех подходящих адресов, недоступности HTTPS, общем сбое Roblox или проблемах с другими доменами. Пользовательский прокси или отдельные DNS-настройки браузера также могут влиять на результат.

Если картинки снова перестали загружаться, запусти исправление повторно: адреса CDN меняются. Для возврата прежних настроек используй **«Отменить фикс»**.

Файл не подписан цифровой подписью издателя. Исходный код доступен в этом репозитории. Подробнее: [технические детали и ограничения](README_RU.md).

## Статус проверки

Автор запроса подтвердил, что версия 1.0 помогла вернуть изображения на его ПК. Это один пользовательский отчёт; версия Windows и провайдер не уточнялись. Переносимые тесты логики пройдены. Подробный объём проверки приведён в [VALIDATION.md](VALIDATION.md).

## Сборка

**Windows / Visual Studio:** открой **x64 Native Tools Command Prompt** и выполни:

```bat
build_msvc.bat
```

**MinGW-w64:**

```sh
bash build_mingw.sh
```

Результат: `build/RobloxIconFix.exe`. Автоматическая сборка и тесты настроены в [GitHub Actions](.github/workflows/build.yml). После успешного запуска workflow файл доступен в его **Artifacts**. Workflow сам не публикует релиз.

## Обратная связь

Если не помогло, создай **Issue**: укажи версию Windows, результат проверки и строки журнала, относящиеся к ошибке. Перед публикацией убери личные пути и адреса. Полный hosts прикладывать не требуется.
