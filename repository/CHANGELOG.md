# Changelog

## 1.0.0 — 2026-10-22

Первый публичный выпуск.

- Русский интерфейс для Windows x64.
- Получение адресов `tr.rbxcdn.com` через Google / Cloudflare DNS-over-HTTPS.
- Проверка HTTPS и загрузки тестового изображения, когда доступен API Roblox.
- Диагностика без изменения hosts.
- Применение адреса только для сервера изображений Roblox.
- Полная резервная копия hosts перед изменением.
- Откат собственных изменений с сохранением сторонних записей.
- Повторная проверка после применения и автоматический откат при неудаче, если hosts не изменён другой программой.
- Журнал проверки и возможность остановить сетевую диагностику.
- Исходники, тесты логики и конфигурация сборки GitHub Actions.

Получено одно подтверждение пользователя об успешном восстановлении изображений. Совместимость со всеми провайдерами не заявляется. Исходный проверенный пользователем `.exe` сохранён без изменений; публичное обозначение версии — `v1.0.0`, номер в окне — `1.0`.
