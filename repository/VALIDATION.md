# Что проверено в версии 1.0.0

## Подтверждение пользователя

22 октября 2026 пользователь, для которого была создана утилита, подтвердил, что она помогла восстановить загрузку изображений в Roblox на его ПК. До применения он показал серые заглушки вместо обложек игр.

Это один пользовательский отчёт. Точная версия Windows, провайдер и выбранный программой IP не сообщались. Отдельная ручная проверка кнопки отката на этом ПК не подтверждалась.

## Выполненные проверки разработки

- Кросс-компиляция C++17 в Windows x64 PE32+ GUI executable, MinGW-w64 GCC 13.
- Проверка таблицы импорта: используются DLL Windows, runtime C++ связан статически.
- Проверка ресурсов PE: значок, информация о версии и манифест прав администратора.
- Тесты логики, включая 2 000 воспроизводимых случайных сочетаний строк hosts. Проверено побайтовое восстановление, повторное применение, сохранение сторонних строк, несколько имён в записи, CRLF/LF, отсутствие завершающего перевода строки, BOM и однобайтовые комментарии.
- Проверки отказа при повреждении собственных блоков, UTF-16 или бинарном hosts, некорректных IPv4 и JSON, неподходящем имени хоста в URL картинки.
- Тесты выполнены с AddressSanitizer и UndefinedBehaviorSanitizer. LeakSanitizer был отключён из-за ограничений среды; отдельная проверка утечек не заявляется.

Исходный `.exe`, получивший пользовательское подтверждение:

```text
Размер: 1085440 байт
SHA-256: 9997a49364ecc13870ada2de9a89f87d3c270b71925a654e69f9dc80439459d1
```

## Что ещё не проверено

- Самостоятельная полная проверка GUI, операций Windows и разных сетевых условий разработчиком: локальная среда сборки — Linux, Wine запустить не удалось.
- Работа на нескольких провайдерах, разных сборках Windows и сетях с прокси.
- Сборка MSVC и запуск нового workflow на GitHub. Они подготовлены, но результат появится только после загрузки проекта и запуска Actions.

В workflow предусмотрены тесты логики на Linux и Windows, а также сборка Windows x64. Сетевые проверки и изменение системного hosts в CI не выполняются. Повторная сборка другим компилятором может иметь другой SHA-256 и требует отдельной проверки перед выпуском.
