# Roblox Icon Fix 1.0

Небольшая утилита для Windows, которая помогает при проблемах с DNS или отдельными узлами сервера картинок `tr.rbxcdn.com`. На форуме разработчиков Roblox опубликованы сообщения о пропавших аватарках, иконках игр и превью у пользователей из России; в обсуждении описан способ с заменой адреса этого домена в hosts.

## Запуск

1. Полностью закрой Roblox.
2. Запусти `RobloxIconFix.exe`. Windows запросит права администратора: они нужны для изменения системного hosts.
3. Нажми **Исправить иконки** и дождись результата.
4. Открой Roblox заново. Утилиту можно закрыть.

**Проверить** запускает диагностику без изменения hosts. **Отменить фикс** удаляет изменения этой утилиты и восстанавливает прежние записи для домена картинок. **Открыть журнал** открывает папку с журналами и резервными копиями. «Стоп» доступен во время сетевой проверки; во время короткого этапа записи и проверки результата отмена недоступна.

Если иконки снова пропали, запусти исправление повторно: адреса CDN могут меняться. Если в журнале указано, что встроенного `curl.exe` нет, требуется Windows 10 версии 1803 или новее либо Windows 11. Сборка рассчитана на x64. Python, .NET и установка сторонних библиотек не нужны.

## Что делает программа

- Запрашивает свежие IPv4-адреса у Google и Cloudflare по DNS-over-HTTPS. Запросы к резолверам используют их известные адреса, сохраняя проверку имени и сертификата HTTPS.
- Получает свежую ссылку на публичную картинку через API Roblox. Вход в аккаунт, пароль и cookie не используются.
- Проверяет текущий и альтернативные адреса CDN с сохранением TLS-проверок. Помимо DNS-ответов есть небольшой резервный список адресов из публичного обсуждения; каждый из них проходит новую сетевую проверку перед использованием.
- Если удалось получить ссылку, проверяет HTTP-ответ, тип содержимого и сигнатуру изображения. При недоступном API отдельный результат сообщает, что подтверждена только связь по HTTPS, а загрузка иконок не проверена. Ответы 403/404 в корне CDN в этом режиме подтверждают лишь TLS-соединение, не доступность конкретной картинки.
- Если тестовая картинка уже загружается, ничего не меняет.
- При применении заменяет только записи `tr.rbxcdn.com` в hosts. Существующие записи этого домена сохраняет в обратимых комментариях; другие имена в общих строках остаются активными. Повторный запуск не создаёт дубликаты собственных блоков.
- Сохраняет полную резервную копию hosts, использует замену файла через Windows ReplaceFile и очищает кэш DNS.
- Проверяет доступность через системное разрешение имени после применения. Если результат не подтверждается, автоматически возвращает прежнее содержимое, при условии что другая программа не успела изменить hosts. При конфликте не затирает чужие изменения и сообщает об ошибке.

Меняется один файл: `%SystemRoot%\System32\drivers\etc\hosts`. Копии и журналы находятся в `%SystemRoot%\System32\drivers\etc\RobloxIconFix-backups`. При обычном откате утилита удаляет свои блоки, а не заменяет весь hosts старой копией — так сохраняются чужие изменения вне этих блоков. Если кто-то вручную отредактировал содержимое блока утилиты, автоматический откат останавливается с объяснением в журнале.

## Ограничения

Это адресное исправление для сервера изображений, а не универсальный обход недоступности Roblox. Оно может не помочь при блокировке всех доступных IP или HTTPS-соединений, сбое самого Roblox, ошибке отдельного плейса либо проблеме с другими доменами. Встроенные текстуры внутри игр могут загружаться с других серверов. Собственные DNS-настройки некоторых браузеров и прокси могут менять результат по сравнению с системной проверкой.

Утилита проверяет прямое соединение IPv4 и не применяет системный прокси к своим диагностическим запросам. Она не меняет DNS-адреса сетевых адаптеров, не устанавливает службы и драйверы, не добавляет автозапуск, не редактирует клиент Roblox и не отключает проверку сертификатов. Файл не имеет цифровой подписи издателя. Исходники прилагаются для проверки и самостоятельной сборки.

## Если нужен ручной откат

Сначала используй **Отменить фикс**. Если блоки были вручную повреждены, открой журнал и найди путь к полной резервной копии `hosts_...bak`, соответствующей нужному действию. Сравни её с текущим hosts, прежде чем восстанавливать весь файл: полная замена также отменит изменения, которые другие программы внесли после создания копии. Не удаляй строки с посторонними доменами.

## Сборка из исходников

MinGW-w64: запусти `bash build_mingw.sh`. При необходимости укажи `CXX` и `WINDRES`. На Windows с Visual Studio Build Tools открой **x64 Native Tools Command Prompt** и запусти `build_msvc.bat` (этот способ не проверялся в текущей среде).

Результат: `build/RobloxIconFix.exe`.

Переносимые тесты логики:

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic tests/core_tests.cpp -o core_tests
./core_tests
```

Сведения о фактически выполненных проверках — в `VALIDATION.md`.
